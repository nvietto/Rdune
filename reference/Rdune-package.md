# Rdune: 'Creates Color Palettes Inspired by Dune'

Enables the use of color palettes inspired by the 'Dune' movies. These
palettes are compatible with 'ggplot2'. See Wickham (2016)
[doi:10.1007/978-3-319-24277-4](https://doi.org/10.1007/978-3-319-24277-4)
for more details on 'ggplot2'.
